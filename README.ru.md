# MihoWRT

[English](README.md)

MihoWRT запускает [Mihomo](https://github.com/MetaCubeX/mihomo) на OpenWrt и добавляет интерфейс LuCI: прозрачное проксирование IPv4/IPv6 (TPROXY), перенаправление DNS, подписки, списки устройств и адресов, автоматическое восстановление. Группами прокси, правилами, провайдерами и DNS управляет Mihomo. Для начала достаточно ссылки на подписку; опытные пользователи могут редактировать YAML.

## Требования

- OpenWrt **25.12 (apk)** или **24.10 (opkg)**, firewall4/nftables. См. [ограничения 24.10](docs/reference.md#openwrt-2410).
- **Минимум 128 МиБ RAM, рекомендуется 256 МиБ.** Большим конфигам (несколько МиБ) нужно **256 МиБ и больше**; на 128 МиБ держите YAML небольшим. Конфиг на 8 МиБ вызвал нехватку памяти во всех проверенных сборках на 128 МиБ, включая 0.10; на 512 МиБ проверка прошла, 256 МиБ не проверяли.
- **100 МиБ и больше свободной флеш-памяти**: ядро ≈12 МиБ в архиве, до ≈55 МиБ после распаковки, ×2 во время обновления; геоданные и панель требуют дополнительного места (панель заняла 5284 КиБ). Размер зависит от версии ядра и архитектуры.
- Обновление ядра работало в VM со 128 МиБ, но в самой низкой точке оставалось лишь ≈6–8 МиБ MemAvailable. Это не гарантия для любого роутера.
- Зависимости: `luci-base cgi-io jq nftables kmod-nft-tproxy curl` (их разрешает менеджер пакетов). Для русского интерфейса нужны `luci-i18n-base-ru` и `luci-i18n-mihowrt-ru`.

## Установка и первый запуск

1. Выполните на роутере от root:
   ```sh
   wget -qO- https://raw.githubusercontent.com/ristavor/mihowrt/main/install.sh | sh
   ```
   Выберите установку и язык. Установщик выбирает APK/IPK, проверяет `SHA256SUMS`, ставит недостающие зависимости и запускает `core-update` **только если ядро отсутствует**. Для русского интерфейса добавьте базовый перевод: `apk add luci-i18n-base-ru` или `opkg update && opkg install luci-i18n-base-ru`.
2. Откройте **LuCI → Службы → MihoWRT**, вставьте ссылку на подписку и нажмите **Подключить**.
3. Проверьте «Обзор»; устройства и исключения находятся на странице **«Трафик»**, поиск проблем — в **«Диагностике»**. Необязательная панель по умолчанию выключена: кнопка **«Установить панель»** на «Обзоре» доступна только при работающей службе; удаление — **«Трафик → Дополнительно»**.

Без терминала сначала скачайте `install.sh`, затем выполните:

```sh
MIHOWRT_ACTION=install MIHOWRT_LANGUAGE=ru sh install.sh
```

## Обновление

Запустите установщик ещё раз. При обновлении APK и IPK сохраняются язык, ядро, пользовательские файлы и состояние службы: работавшая перезапустится, остановленная останется остановленной; отключённый автозапуск не включится сам. <!-- verify: 24.10 hooks (sr-opkg-vm) --> Ядро Mihomo обновляется отдельно на «Обзоре» или командой `mihowrt core-update`. Обновление подписки заменяет YAML, включая ручные правки. Поддерживается обновление с 0.9.0 и новее; с 0.8 и старше сначала удалите пакет, затем установите заново.

## Удаление

Выполните `MIHOWRT_ACTION=remove sh install.sh` или команды своего менеджера пакетов (не указывайте пакет перевода, если он не установлен):

```sh
apk del luci-i18n-mihowrt-ru luci-app-mihowrt
# OpenWrt 24.10:
opkg remove luci-i18n-mihowrt-ru luci-app-mihowrt
```

Удаление APK и IPK останавливает службу, удаляет ядро, панель и геоданные. YAML, списки, настройки UCI и ID устройства остаются. <!-- verify: 24.10 hooks (sr-opkg-vm) --> **`mihowrt uninstall` лишь очищает рабочее состояние, ядро и геоданные; сам пакет эта команда не удаляет.**

## Если GitHub недоступен

Если заблокирован только `raw.githubusercontent.com`, может помочь зеркало установщика с привязкой к тегу релиза:

```sh
wget -qO- https://cdn.jsdelivr.net/gh/ristavor/mihowrt@v0.11.0/install.sh | sh
```

Это стороннее зеркало — дополнительная точка доверия: его скрипт выполняется от root. Оно не заменяет источник пакетов и ядра. Установщик принимает доверенный адрес каталога релиза с пакетами и `SHA256SUMS`:

```sh
MIHOWRT_ACTION=install MIHOWRT_RELEASE_URL=https://mirror.example/mihowrt/v0.11.0 sh install.sh
```

Эта переменная меняет только источник пакетов MihoWRT, не ядра Mihomo. Для ручного переноса скачайте на ПК нужный `.apk` (25.12) или `.ipk` (24.10), необязательный пакет русского перевода и `SHA256SUMS` из [релиза MihoWRT](https://github.com/ristavor/mihowrt/releases), а также Linux-ядро `.gz` **для архитектуры процессора роутера** из [релизов Mihomo](https://github.com/MetaCubeX/mihomo/releases). На ПК сверьте контрольные суммы пакетов и опубликованный хеш ядра. Передайте файлы через `scp` (вместо `router` укажите SSH-адрес своего роутера):

```sh
scp ./file.apk ./mihomo.gz root@router:/tmp/
# Для 24.10 используйте ./file.ipk; при необходимости передайте пакет перевода.
```

На роутере сначала установите недостающие зависимости из репозиториев OpenWrt, затем:

```sh
cd /tmp
apk add --allow-untrusted ./file.apk
# Для OpenWrt 24.10 вместо этого:
opkg install ./file.ipk
mihowrt core-update --file /tmp/mihomo.gz
/etc/init.d/mihowrt enable
```

Аналогично установите необязательный пакет перевода и выполните шаги 2–3 выше. Если репозитории тоже недоступны, перенесите с ПК все недостающие зависимости под архитектуру и версию ядра OpenWrt. Установка локального ядра пропускает проверку хеша релиза (с предупреждением в журнале), но проверяет работу ядра перед заменой. Пакеты не подписаны: `SHA256SUMS` защищает от повреждения загрузки, не от взлома релиза.

## Частые вопросы

- **Где переключатель режима?** Его нет: настройки DNS в YAML выбирают «Через прокси только выбранный трафик» или «Весь трафик через прокси, кроме исключений». См. [режимы](docs/user-guide.md#modes).
- **Нужна ли панель?** Нет. MihoWRT работает без неё; установка занимает флеш-память и перезапускает службу.
- **Возвращает ли «Остановить» обычную сеть?** Да, политика DNS и маршрутизации MihoWRT удаляется. После повторных ошибок DNS watchdog тоже переводит трафик напрямую; это не аварийная блокировка сети (kill-switch).
- **Можно ли сохранить свой YAML?** Да. MihoWRT создаёт отдельный рабочий файл; обновление подписки заменяет сохранённый оригинал. Редактор позволяет восстановить предыдущий YAML.
