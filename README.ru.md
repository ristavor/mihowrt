# MihoWRT

[English](README.md)

MihoWRT запускает [Mihomo](https://github.com/MetaCubeX/mihomo) на OpenWrt и добавляет интерфейс LuCI: прозрачное проксирование IPv4/IPv6 (TPROXY), перенаправление DNS, подписки, списки устройств и адресов, автоматическое восстановление. Группами прокси, правилами, провайдерами и DNS управляет Mihomo. Для начала достаточно ссылки на подписку; опытные пользователи могут редактировать YAML.

## Требования

- OpenWrt **25.12 (apk)** или **24.10 (opkg)**, firewall4/nftables. См. [ограничения 24.10](docs/reference.md#openwrt-2410).
- **Минимум 128 МиБ RAM, рекомендуется 256 МиБ.** Большим конфигам (несколько МиБ) нужно **256 МиБ и больше**; на 128 МиБ держите YAML небольшим. Конфиг на 8 МиБ вызвал нехватку памяти во всех проверенных сборках на 128 МиБ, включая 0.10; на 512 МиБ проверка прошла, 256 МиБ не проверяли.
- **100 МиБ и больше свободной флеш-памяти — безопасный запас**: ядро ≈12 МиБ в архиве, до ≈55 МиБ после распаковки, ×2 во время обновления; геоданные и панель требуют дополнительного места (панель заняла 5284 КиБ). Размер зависит от версии ядра и архитектуры; сжимающие файловые системы UBIFS/JFFS2 требуют меньше места. Установщик проверяет наличие 2 МиБ; обновление ядра — свободное место ≥ размер архива + 4 МиБ. Если при распаковке место кончится, старое ядро сохранится.
- Обновление ядра работало в VM со 128 МиБ, но в самой низкой точке оставалось лишь ≈6–8 МиБ MemAvailable. Это не гарантия для любого роутера.
- Зависимости: `luci-base cgi-io jq nftables kmod-nft-tproxy curl` (их разрешает менеджер пакетов). Для русского интерфейса нужны `luci-i18n-base-ru` и `luci-i18n-mihowrt-ru`.

## Установка и первый запуск

1. Выполните на роутере от root (`wget` есть в стандартных образах OpenWrt; установщик добавит `curl`, если его нет):
   ```sh
   wget -qO- https://raw.githubusercontent.com/ristavor/mihowrt/main/install.sh | sh
   ```
   Если curl уже установлен: `curl -fsSL https://raw.githubusercontent.com/ristavor/mihowrt/main/install.sh | sh`. Выберите установку и язык. Установщик выбирает APK/IPK, проверяет `SHA256SUMS`, ставит недостающие зависимости и запускает `core-update` **только если ядро отсутствует**. Для русского интерфейса добавьте базовый перевод: `apk add luci-i18n-base-ru` или `opkg update && opkg install luci-i18n-base-ru`.
2. Откройте **LuCI → Службы → MihoWRT**, вставьте ссылку на подписку и нажмите **Подключить**.
3. Проверьте «Обзор»; устройства и исключения находятся на странице **«Трафик»**, поиск проблем — в **«Диагностике»**. Необязательная панель по умолчанию выключена: кнопка **«Установить панель»** на «Обзоре» доступна только при работающей службе; удаление — **«Трафик → Дополнительно»**.

Чтобы сохранить установщик, скачайте его и запустите с явным указанием действия и языка; вариант через pipe тоже работает без терминала:

```sh
wget -O install.sh https://raw.githubusercontent.com/ristavor/mihowrt/main/install.sh
MIHOWRT_ACTION=install MIHOWRT_LANGUAGE=ru sh install.sh
wget -qO- https://raw.githubusercontent.com/ristavor/mihowrt/main/install.sh | MIHOWRT_ACTION=install MIHOWRT_LANGUAGE=ru sh
```

## Обновление

Запустите установщик ещё раз. При обновлении APK и IPK сохраняются язык, ядро, пользовательские файлы и состояние службы: работавшая перезапустится, остановленная останется остановленной; отключённый автозапуск не включится сам. Ядро Mihomo обновляется отдельно на «Обзоре» или командой `mihowrt core-update`. Обновление подписки заменяет YAML, включая ручные правки. Поддерживается обновление с 0.9.0 и новее; с 0.8 и старше сначала удалите пакет, затем установите заново.

## Удаление

Выполните `MIHOWRT_ACTION=remove sh install.sh` или команды своего менеджера пакетов (не указывайте пакет перевода, если он не установлен):

```sh
apk del luci-i18n-mihowrt-ru luci-app-mihowrt
# OpenWrt 24.10:
opkg remove luci-i18n-mihowrt-ru luci-app-mihowrt
```

Удаление APK и IPK останавливает службу, очищает DNS/nftables/маршруты, запись cron, ядро, панель, геоданные, метаданные подписки (`subscription.json`), сохранённый выбор прокси (`cache.db`) и кеш удалённых списков (`policy-cache`). YAML и `config.yaml.bak`, списки, настройки UCI и `/etc/mihowrt/hwid` остаются: после переустановки провайдер видит то же устройство. **`mihowrt uninstall` выполняет эту очистку, но сам пакет не удаляет.**

## Если GitHub недоступен

Если заблокирован только `raw.githubusercontent.com`, может помочь зеркало установщика с привязкой к тегу релиза:

```sh
wget -qO- https://cdn.jsdelivr.net/gh/ristavor/mihowrt@v0.11.0/install.sh | sh
```

Это стороннее зеркало — дополнительная точка доверия: его скрипт выполняется от root. Пакеты и ядро оно не зеркалирует: они по-прежнему загружаются с GitHub. Используйте доверенное HTTPS-зеркало: в каталоге должны быть `SHA256SUMS`, `luci-app-mihowrt.apk` (25.12) / `luci-app-mihowrt.ipk` (24.10), а для русского интерфейса — `luci-i18n-mihowrt-ru.apk` / `luci-i18n-mihowrt-ru.ipk`. Установщик скачивает эти **фиксированные имена**, не имена с версией; обычный HTTP не защищает файл контрольных сумм от подмены:

```sh
MIHOWRT_ACTION=install MIHOWRT_RELEASE_URL=https://mirror.example/mihowrt/v0.11.0 sh install.sh
```

Для проверки rc используйте `MIHOWRT_RELEASE_URL=https://github.com/ristavor/mihowrt/releases/download/v0.11.0-rc1` (при необходимости замените номер rc). Переменная меняет только источник пакетов MihoWRT, не ядра Mihomo. Для ручного переноса скачайте на ПК нужный `.apk` (25.12) или `.ipk` (24.10), необязательный пакет русского перевода и `SHA256SUMS` из [релиза MihoWRT](https://github.com/ristavor/mihowrt/releases), а также Linux-ядро `.gz` **для архитектуры процессора роутера** (`DISTRIB_ARCH` в `/etc/openwrt_release`; [таблица файлов](docs/reference.md#core-asset-selection)) из [релизов Mihomo](https://github.com/MetaCubeX/mihomo/releases). Сохраните исходные имена скачанных пакетов. На ПК проверьте только нужные строки из `SHA256SUMS` (для 24.10 замените `.apk` на `.ipk`; добавьте строку перевода, если скачали его) и отдельно сверьте опубликованный хеш ядра:

```sh
awk '$2 == "luci-app-mihowrt.apk" { print }' SHA256SUMS | sha256sum -c -
# Для русского интерфейса также:
awk '$2 == "luci-i18n-mihowrt-ru.apk" { print }' SHA256SUMS | sha256sum -c -
```

Передайте файлы через `scp -O`: в штатном Dropbear нет SFTP-сервера, поэтому нужен старый протокол SCP. Вместо `router` укажите SSH-адрес своего роутера:

```sh
scp -O ./luci-app-mihowrt.apk ./mihomo.gz root@router:/tmp/
# Для 24.10 используйте ./luci-app-mihowrt.ipk; при необходимости передайте пакет перевода.
```

На роутере установите зависимости из репозиториев OpenWrt, затем перенесённые файлы (выберите свой менеджер пакетов):

```sh
cd /tmp
apk update && apk add luci-base cgi-io jq nftables kmod-nft-tproxy curl
apk add --allow-untrusted ./luci-app-mihowrt.apk
# Для OpenWrt 24.10 вместо этого:
opkg update && opkg install luci-base cgi-io jq nftables kmod-nft-tproxy curl
opkg install ./luci-app-mihowrt.ipk
mihowrt core-update --file /tmp/mihomo.gz
/etc/init.d/mihowrt enable
# Удалите только перенесённые файлы: --file оставляет исходник в tmpfs:
rm /tmp/mihomo.gz /tmp/luci-app-mihowrt.apk  # для 24.10 — .ipk
```

Для русского интерфейса также выполните `apk add luci-i18n-base-ru` и `apk add --allow-untrusted ./luci-i18n-mihowrt-ru.apk` либо `opkg install luci-i18n-base-ru ./luci-i18n-mihowrt-ru.ipk`; затем удалите перенесённый файл перевода. После этого выполните шаги 2–3 выше. Если репозитории тоже недоступны, перенесите с ПК все недостающие зависимости под архитектуру и версию ядра OpenWrt. Установка локального ядра пропускает проверку хеша релиза (с предупреждением в журнале), но проверяет работу ядра перед заменой. Пакеты не подписаны: `SHA256SUMS` защищает от повреждения загрузки, не от взлома релиза.

## Частые вопросы

- **Где переключатель режима?** Его нет: настройки DNS в YAML выбирают «Через прокси только выбранный трафик» или «Весь трафик через прокси, кроме исключений». См. [режимы](docs/user-guide.md#modes).
- **Нужна ли панель?** Нет. MihoWRT работает без неё; установка занимает флеш-память и перезапускает службу.
- **Возвращает ли «Остановить» обычную сеть?** Да, политика DNS и маршрутизации MihoWRT удаляется. После повторных ошибок DNS watchdog тоже переводит трафик напрямую; это не аварийная блокировка сети (kill-switch).
- **Можно ли сохранить свой YAML?** Да. MihoWRT создаёт отдельный рабочий файл; обновление подписки заменяет сохранённый оригинал. Редактор позволяет восстановить предыдущий YAML.
